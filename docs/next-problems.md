## p0007 (実装済み): WOWII 予想 200

> 連結グラフ $G$ が $\mathrm{tree}(G) = \lceil 1 + \ell_{\mathrm{avg}}(G)\rceil$
> を満たせば、$G$ はハミルトン路をもつ。

$\mathrm{tree}(G)$ は最大誘導木の位数 (p0005 で実装済み)、
$\ell_{\mathrm{avg}}(G) = S(G)/n$、$S(G) = \sum_v \alpha(G[N(v)])$ (p0006 で
実装済み)。**新しい不変量は 1 つも要らない** ので、`checkgraph.py` に手を
入れずに書ける (＝ 既存問題の検証記録を壊さない)。

### 証人の設計 (2 モード、p0006 と同型)

$t = \lceil 1 + \ell_{\mathrm{avg}}\rceil = 1 + \lceil S/n \rceil$ と置く
($S$ と $n$ から整数演算だけで決まるので検証器が安く計算できる)。

* **モード 0 (路)**: ハミルトン路 1 本。結論が真なので仮定を調べる必要がない。
* **モード 1 (誘導木)**: 位数 $t+1$ の誘導木の頂点集合。$\mathrm{tree}(G) > t$
  すなわち仮定が偽であることが線形時間で確定する。

どちらの分岐も NP 困難な $\mathrm{tree}(G)$ を検証器が解き直さない。

### 手証明の候補 (すべて要 machine-check)

**定理 A (星の下界)。** 任意のグラフ $G$ と頂点 $v$ に対し、$N(v)$ の最大独立
集合 $A$ を取ると $\{v\} \cup A$ は星 $K_{1,|A|}$ を誘導する。よって

$$\mathrm{tree}(G) \ \ge\ 1 + \ell_{\max}(G) \ \ge\ 1 + \ell_{\mathrm{avg}}(G),$$

$\mathrm{tree}$ は整数なので $\mathrm{tree}(G) \ge \lceil 1 + \ell_{\mathrm{avg}}(G)\rceil = t$。
**予想 200 の仮定はこの下界の等号成立条件**である。

**定理 B (言い換え)。** 仮定 $\mathrm{tree}(G) = t$ は

$$\mathrm{tree}(G) = 1 + \ell_{\max}(G) \quad\text{かつ}\quad
\ell_{\max}(G) = \lceil \ell_{\mathrm{avg}}(G)\rceil$$

と同値。すなわち「最大誘導木が星で達成され、かつ局所独立数がほぼ一定」。
$n \le 9$ の全連結グラフ 273,192 個で両者の個数が完全に一致することを実測済み
(不一致 0 件)。

**系 C (木)。** 木では近傍が独立なので $\ell(v) = \deg(v)$、
$S = 2(n-1)$、$\lceil 1 + \ell_{\mathrm{avg}}\rceil = 3$ ($n \ge 3$)。一方
$\mathrm{tree}(T) = n$。よって $n \ge 4$ の木では仮定が空虚で、モード 1 の
証人は位数 4 の誘導部分木で足りる。p0006 と同じく木の族は「分類しない族」に
できる。

### 実測 (n ≤ 9 の全連結グラフ)

| n | 連結グラフ | 仮定を満たす | $\mathrm{tree} < t$ | 反例 |
|---|---|---|---|---|
| 4 | 6 | 4 | 0 | 0 |
| 5 | 21 | 8 | 0 | 0 |
| 6 | 112 | 23 | 0 | 0 |
| 7 | 853 | 98 | 0 | 0 |
| 8 | 11,117 | 535 | 0 | 0 |
| 9 | 261,080 | 3,790 | 0 | 0 |

`tree < t` が 1 件も無いのは定理 A の帰結 (実測はその機械照合になっている)。
仮定を満たすのは $n = 9$ で 1.5% しかないので、予想は空虚ではない。

### 予想 194 (p0006) との関係

* 仮定 200 を満たす 4,461 個 ($n \le 9$) のうち **4,357 個 (97.7%) は仮定 194 も
  満たす**が、**104 個は満たさない** (最小は $n = 7$ の `F?zew`)。
  逆に仮定 194 を満たすグラフの方が桁違いに多い。**2 つの仮定クラスは
  どちらも他方を含まない。**
* したがって予想 200 は予想 194 の系ではなく、独立に検証する価値がある。
* 逆向きの非包含 (194 の仮定は満たすが 200 の仮定は満たさない) は $P_4$ 1 個で
  足りる: $S = 6$、$\ell_{\mathrm{avg}} = 3/2$、$t = 3$、$\alpha = 2 \le 1 + 3/2$、
  一方 $\mathrm{tree}(P_4) = 4 \ne 3$。論文では命題として書き、走査結果に頼らない。
* 使えそうで使えなかった補題: $\alpha(G) \le \mathrm{tree}(G)$ は**偽**。
  $n = 8$ の `G?Bem[` が $\alpha = 5 > 4 = \mathrm{tree}$ で反例
  ($n \le 8$ での差は高々 1)。これが成り立てば「194 ⟹ 200 ($n \mid S$ のとき)」
  が言えたが、成り立たないので却下した。

### 未証明の観察 (論文では「走査範囲での分類」として書く)

仮定 200 を満たす**三角形なし**グラフは、$n \le 9$ の 18 個すべてが
**二部かつ均衡** ($\bigl||X|-|Y|\bigr| \le 1$) だった。三角形なしなら
$\ell(v) = \deg(v)$ なので仮定は「$\Delta = \lceil \bar d\rceil$ かつ
$\mathrm{tree} = \Delta + 1$」と読める。二部連結グラフで
$\mathrm{tree}(G) \ge \max(|X|,|Y|)$ が言えれば
$|X| \le 1 + \Delta \le 1 + |Y|$ から均衡性が従うが、この補題は未確認。

**p0007 の論文には入れなかった。** 証明書に三角形なしグラフの二部分割を
記録する追加フィールドが要るのに対し、得られる主張が「走査範囲での観察」
止まりで弱いため。補題が示せたら定理として書き足す。

## p0008 (実装済み): WOWII 予想 141 — 証明が付いた

> $\mathrm{girth}(G)/2 - 1 + \ell_{\max}(G) \le \mathrm{tree}(G)$。

証人の形は p0005 と同じ (誘導木 1 個で下から閉じる) で追加コストが最小、
というのが着手理由だったが、走査を書く前に**初等的な証明が付いた**。
概略は以下 (詳細は `papers/p0008_*/main.pdf` §3)。

* 内周 $\ge 4$ なら三角形がないので $\ell(v) = \deg(v)$、よって
  $\ell_{\max} = \Delta$。内周 0 (森) と 3 は星の下界 (予想 140) だけで
  狭義に片付く。
* **球の補題**: $r = \lfloor g/2 \rfloor - 1$ なら、**任意の**頂点 $v$ で
  $G[B_r(v)]$ は木。$\lceil \cdot \rceil$ にすると $C_5$ が反例になる。
* 閉路があるので任意の頂点の離心数は $r + 1$ 以上。最大次数の頂点 $v^*$ で
  $\lvert B_r(v^*) \rvert \ge 1 + \Delta + (r-1)$、これが誘導木なので
  $\mathrm{tree} \ge \Delta + r$。
* 内周が**奇数**ならレベル $r+1$ の頂点を 1 つ足せて $+1$。これで
  **有理数版** $g/2 - 1 + \ell_{\max} \le \mathrm{tree}$ が閉じる
  (Lean 形式化の整数除算版より真に強い)。
* 等号は「内周 4 かつ $\mathrm{tree} = 1 + \Delta$」に完全分類。
* Moore 型の強化 $\mathrm{tree} \ge 1 + \Delta \sum_{i<r} (\delta-1)^i$ も付く
  (Heawood グラフで等号)。

走査 (28 族 13,402,242 グラフ) は反例探索ではなく**証明の各ステップの機械照合**
として残した。方法論側の整理は `methodology.md` §4 を参照。

## p0009 (実装済み): WOWII 予想 2 — 部分的な証明 + 新しい予想 B'

> $2(\overline{\ell}(G) - 1) \le L_s(G)$。$L_s$ は葉数 (全域木がもつ葉の最大個数)、
> $\ell(v) = \alpha(G[N(v)])$、$\overline{\ell}$ はその平均。

証人は「ある全域木の葉集合」1 個 (32 bit マスク)。検証器は補集合が
**連結支配集合**であることだけを見る (それで $L_s \ge |L|$ が従う)。

**一次資料の確認 (2026-07-27)**: WOWII の未解決リスト
`.../research/wowII/open.html` に `O 2. If G is a simple connected graph,
then L_s(G) >= 2(average of l(v) - 1)` として掲載されており、解決済みリスト
`resolved.htm` (項目は `T`/`F` 印) には $L_s$ のこの下界は無い。取得した
スナップショットは `data/refs/wowii_{open,resolved,all,list,menu}.html`
(外部データなので git 追跡外。sha256 先頭 16 桁: open `6348a7e3f007d60c`、
resolved `1eafeae043537646`、all `9a364164f397c2f0`)。

* **命題 2.1**: $n \ge 3$ で $L_s(G) = n - \gamma_c(G)$。$K_2$ だけが例外
  ($L_s = 2$, $\gamma_c = 1$)。
* **定理 3.2 (二重星定理)**: **任意の辺** $uv$ で
  $L_s(G) \ge \lvert N(u) \cup N(v)\rvert - 2$。系として $L_s \ge \Delta$。
  走査ではこの二重星がそのまま証人になり、13,402,070 / 13,402,242 個
  (99.999%) を閉じた (貪欲 159 個、厳密 13 個)。
* **予想 4.1 (B', 本稿)**: $\max_{uv \in E} \lvert N(u) \cup N(v)\rvert
  \ge 2\overline{\ell}(G)$。**B' $\Rightarrow$ 予想 2** (系 4.2)。
* **補題 4.3**: $\sum_{uv \in E} \lvert N(u) \cup N(v)\rvert \ge
  \sum_v d(v)\ell(v)$、等号は三角形なしと同値。
  ($\sum_{uv} \lvert N \cup N\rvert = \sum_v d(v)^2 - 3T$、Gallai の
  $\tau_v = d(v) - \ell(v)$、頂点ごとの $d(v)\tau_v \ge e_v$ による。)
* **予想 4.4 (A, 本稿)**: $n \sum_{uv \in E} \lvert N(u) \cup N(v)\rvert
  \ge 2mS$ (B' の max を平均に置き換えた強化版)。
  **A $\Rightarrow$ B' $\Rightarrow$ 予想 2** (系 4.5)。
* **定理 4.6 (共分散定理)**: $\mathrm{Cov}(d, \ell) \ge 0$、すなわち
  $n \sum_v d(v)\ell(v) \ge 2mS$ ならば A が従う。三角形なしのときは
  $\ell = d$ なので $\mathrm{Cov} = \mathrm{Var} \ge 0$ で自動的に成立
  (系 4.7 — 以前の Cauchy--Schwarz による証明の一般化)。
* **定理 5.1 (帯)**: $2S \le 4n$ (自明帯)、$2S \le n(\Delta+2)$ ($\Delta$ 帯)、
  $n \sum_v d(v)\ell(v) \ge 2mS$ (共分散帯) で予想 2 は閉じる。実測で
  **13,402,228 / 13,402,242 = 99.9999%** が本稿の定理だけで片付き、引用した
  下界 (Kleitman--West, Storer) を足すと残りは**ちょうど 1 個**。
* 等号は 13 個に完全分類: $C_4, \dots, C_{10}$ と $K_{3,3}, Q_3, K_{4,4},
  K_{5,5}, K_{5,5} - M, K_{6,6} - M$ (すべて三角形なし正則、$L_s = 2\Delta - 2$)。
  B' の等号は 8,796 個、A の等号も同数。反例はいずれもゼロ。

**未解決**: A (したがって共分散不等式 $\mathrm{Cov}(d,\ell) \ge 0$) の一般証明。
$\ell$ は $d$ の単調関数ではないので $d$ と $\ell$ の正の相関は自明ではないが、
1340 万個で反例ゼロ。本稿の定理で閉じない 14 個は $n = 9$ の 2 個
(`H?~vfbk` が唯一の hard、`H?~vfrs`) と $n = 10$ の 12 個で、すべて
$\delta \ge 4$。証明書はこの 14 個を graph6 で名指しし、検証器が独立に
数え直して照合する。

> **方法論上の収穫**: 予想を**強くした**ら**証明しやすくなった**。
> 予想 2 (葉数、NP 困難) ← B' (局所量の max) ← A (局所量の平均) ←
> 共分散 $\ge 0$、と登るたびに、max では使えなかった数え上げ・包除の議論が
> 効くようになる。$\Delta$ 帯までで 99.656% だったものが、平均版に移った
> 瞬間 99.9999% になった。

## 他の有望な候補 (p0010 以降)

* **予想 198a**: `b(G) <= 2 + averageEccentricity(G)` ならば traceable。
  予想 194・200 と同じ「含意 + ハミルトン路」型なので同じ 2 モード証人が使える。

  「内周 + 離心数 $\le \mathrm{tree}$」型
  (142: $\frac{2}{3}g + \mathrm{ecc}(B)$、144: $g - 1 + \mathrm{ecc}^\circ(C)$)。
  p0008 の球の補題は内周から誘導木の下界を作る汎用の道具なので、

  届かない (球の半径は内周で頭打ちになる) ため、二重に球を取るなどの
  追加のアイデアが要る。
* **予想 322 / 316 / 314**: 結論が well-totally-dominated という**性質**で、
  否定側の証人が作りにくい。後回し。
