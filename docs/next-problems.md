## p0007 (実装済み): WOWII 予想 200 — 反例の無限族が出た

> 連結グラフ $G$ が $\mathrm{tree}(G) = \lceil 1 + \ell_{\mathrm{avg}}(G)\rceil$
> を満たせば、$G$ はハミルトン路をもつ。

**この予想は偽である。** 位数 11 の反例が 2026-07-21 に J. Prajapati により
公表され `resolved.htm` に載った。p0007 はそれを独立に検証したうえで、
下の定理 B (仮定 = 星の下界の等号成立条件) を設計図として位数 $2q+1$ の
**反例の無限族** $G_q$ を構成し ($S = 4q+4$、閾値 $=\mathrm{tree}= 4$、葉 $q-2$ 枚)、
位数 4--10 の全連結グラフに反例が無いことと合わせて**最小反例の位数が
ちょうど 11** であることを確定した。以下の設計メモはそのまま有効で、
網羅検証のパート (証人 2 モード) は最小性の証明に使っている。

$\mathrm{tree}(G)$ は最大誘導木の位数 (p0005 で実装済み)、
$\ell_{\mathrm{avg}}(G) = S(G)/n$、$S(G) = \sum_v \alpha(G[N(v)])$ (p0006 で
実装済み)。**新しい不変量は 1 つも要らない** ので、`checkgraph.py` に手を
入れずに書ける (＝ 既存問題の検証記録を壊さない)。

### 証人の設計 (2 モード、p0006 と同型)

$t = \lceil 1 + \ell_{\mathrm{avg}}\rceil = 1 + \lceil S/n \rceil$ と置く
($S$ と $n$ から整数演算だけで決まるので検証器が安く計算できる)。

* **モード 0 (路)**: ハミルトン路 1 本。結論が真なので仮定を調べる必要がない。
* **モード 1 (誘導木)**: 位数 $t+1$ の誘導木の頂点集合。$\mathrm{tree}(G) > t$
  すなわち仮定が偽であることが線形時間で確定する。

どちらの分岐も NP 困難な $\mathrm{tree}(G)$ を検証器が解き直さない。

### 手証明の候補 (すべて要 machine-check)

**定理 A (星の下界)。** 任意のグラフ $G$ と頂点 $v$ に対し、$N(v)$ の最大独立
集合 $A$ を取ると $\{v\} \cup A$ は星 $K_{1,|A|}$ を誘導する。よって

$$\mathrm{tree}(G) \ \ge\ 1 + \ell_{\max}(G) \ \ge\ 1 + \ell_{\mathrm{avg}}(G),$$

$\mathrm{tree}$ は整数なので $\mathrm{tree}(G) \ge \lceil 1 + \ell_{\mathrm{avg}}(G)\rceil = t$。
**予想 200 の仮定はこの下界の等号成立条件**である。

**定理 B (言い換え)。** 仮定 $\mathrm{tree}(G) = t$ は

$$\mathrm{tree}(G) = 1 + \ell_{\max}(G) \quad\text{かつ}\quad
\ell_{\max}(G) = \lceil \ell_{\mathrm{avg}}(G)\rceil$$

と同値。すなわち「最大誘導木が星で達成され、かつ局所独立数がほぼ一定」。
$n \le 9$ の全連結グラフ 273,192 個で両者の個数が完全に一致することを実測済み
(不一致 0 件)。

**系 C (木)。** 木では近傍が独立なので $\ell(v) = \deg(v)$、
$S = 2(n-1)$、$\lceil 1 + \ell_{\mathrm{avg}}\rceil = 3$ ($n \ge 3$)。一方
$\mathrm{tree}(T) = n$。よって $n \ge 4$ の木では仮定が空虚で、モード 1 の
証人は位数 4 の誘導部分木で足りる。p0006 と同じく木の族は「分類しない族」に
できる。

### 実測 (n ≤ 9 の全連結グラフ)

| n | 連結グラフ | 仮定を満たす | $\mathrm{tree} < t$ | 反例 |
|---|---|---|---|---|
| 4 | 6 | 4 | 0 | 0 |
| 5 | 21 | 8 | 0 | 0 |
| 6 | 112 | 23 | 0 | 0 |
| 7 | 853 | 98 | 0 | 0 |
| 8 | 11,117 | 535 | 0 | 0 |
| 9 | 261,080 | 3,790 | 0 | 0 |

`tree < t` が 1 件も無いのは定理 A の帰結 (実測はその機械照合になっている)。
仮定を満たすのは $n = 9$ で 1.5% しかないので、予想は空虚ではない。

### 予想 194 (p0006) との関係

* 仮定 200 を満たす 4,461 個 ($n \le 9$) のうち **4,357 個 (97.7%) は仮定 194 も
  満たす**が、**104 個は満たさない** (最小は $n = 7$ の `F?zew`)。
  逆に仮定 194 を満たすグラフの方が桁違いに多い。**2 つの仮定クラスは
  どちらも他方を含まない。**
* したがって予想 200 は予想 194 の系ではなく、独立に検証する価値がある。
* 逆向きの非包含 (194 の仮定は満たすが 200 の仮定は満たさない) は $P_4$ 1 個で
  足りる: $S = 6$、$\ell_{\mathrm{avg}} = 3/2$、$t = 3$、$\alpha = 2 \le 1 + 3/2$、
  一方 $\mathrm{tree}(P_4) = 4 \ne 3$。論文では命題として書き、走査結果に頼らない。
* 使えそうで使えなかった補題: $\alpha(G) \le \mathrm{tree}(G)$ は**偽**。
  $n = 8$ の `G?Bem[` が $\alpha = 5 > 4 = \mathrm{tree}$ で反例
  ($n \le 8$ での差は高々 1)。これが成り立てば「194 ⟹ 200 ($n \mid S$ のとき)」
  が言えたが、成り立たないので却下した。

### 未証明の観察 (論文では「走査範囲での分類」として書く)

仮定 200 を満たす**三角形なし**グラフは、$n \le 9$ の 18 個すべてが
**二部かつ均衡** ($\bigl||X|-|Y|\bigr| \le 1$) だった。三角形なしなら
$\ell(v) = \deg(v)$ なので仮定は「$\Delta = \lceil \bar d\rceil$ かつ
$\mathrm{tree} = \Delta + 1$」と読める。二部連結グラフで
$\mathrm{tree}(G) \ge \max(|X|,|Y|)$ が言えれば
$|X| \le 1 + \Delta \le 1 + |Y|$ から均衡性が従うが、この補題は未確認。

**p0007 の論文には入れなかった。** 証明書に三角形なしグラフの二部分割を
記録する追加フィールドが要るのに対し、得られる主張が「走査範囲での観察」
止まりで弱いため。補題が示せたら定理として書き足す。

## p0008 (実装済み): WOWII 予想 141 — 証明が付いた

> $\mathrm{girth}(G)/2 - 1 + \ell_{\max}(G) \le \mathrm{tree}(G)$。

証人の形は p0005 と同じ (誘導木 1 個で下から閉じる) で追加コストが最小、
というのが着手理由だったが、走査を書く前に**初等的な証明が付いた**。
概略は以下 (詳細は `papers/p0008_*/main.pdf` §3)。

* 内周 $\ge 4$ なら三角形がないので $\ell(v) = \deg(v)$、よって
  $\ell_{\max} = \Delta$。内周 0 (森) と 3 は星の下界 (予想 140) だけで
  狭義に片付く。
* **球の補題**: $r = \lfloor g/2 \rfloor - 1$ なら、**任意の**頂点 $v$ で
  $G[B_r(v)]$ は木。$\lceil \cdot \rceil$ にすると $C_5$ が反例になる。
* 閉路があるので任意の頂点の離心数は $r + 1$ 以上。最大次数の頂点 $v^*$ で
  $\lvert B_r(v^*) \rvert \ge 1 + \Delta + (r-1)$、これが誘導木なので
  $\mathrm{tree} \ge \Delta + r$。
* 内周が**奇数**ならレベル $r+1$ の頂点を 1 つ足せて $+1$。これで
  **有理数版** $g/2 - 1 + \ell_{\max} \le \mathrm{tree}$ が閉じる
  (Lean 形式化の整数除算版より真に強い)。
* 等号は「内周 4 かつ $\mathrm{tree} = 1 + \Delta$」に完全分類。
* Moore 型の強化 $\mathrm{tree} \ge 1 + \Delta \sum_{i<r} (\delta-1)^i$ も付く
  (Heawood グラフで等号)。

走査 (28 族 13,402,242 グラフ) は反例探索ではなく**証明の各ステップの機械照合**
として残した。方法論側の整理は `methodology.md` §4 を参照。

## p0009 (実装済み): WOWII 予想 2 — 部分的な証明 + 新しい予想 B'

> $2(\overline{\ell}(G) - 1) \le L_s(G)$。$L_s$ は葉数 (全域木がもつ葉の最大個数)、
> $\ell(v) = \alpha(G[N(v)])$、$\overline{\ell}$ はその平均。

証人は「ある全域木の葉集合」1 個 (32 bit マスク)。検証器は補集合が
**連結支配集合**であることだけを見る (それで $L_s \ge |L|$ が従う)。

**一次資料の確認 (2026-07-27)**: WOWII の未解決リスト
`.../research/wowII/open.html` に `O 2. If G is a simple connected graph,
then L_s(G) >= 2(average of l(v) - 1)` として掲載されており、解決済みリスト
`resolved.htm` (項目は `T`/`F` 印) には $L_s$ のこの下界は無い。取得した
スナップショットは `data/refs/wowii_{open,resolved,all,list,menu}.html`
(外部データなので git 追跡外。sha256 先頭 16 桁: open `6348a7e3f007d60c`、
resolved `1eafeae043537646`、all `9a364164f397c2f0`)。

* **命題 2.1**: $n \ge 3$ で $L_s(G) = n - \gamma_c(G)$。$K_2$ だけが例外
  ($L_s = 2$, $\gamma_c = 1$)。
* **定理 3.2 (二重星定理、既知)**: **任意の辺** $uv$ で
  $L_s(G) \ge \lvert N(u) \cup N(v)\rvert - 2$。系として $L_s \ge \Delta$。
  **本稿の結果ではない**: WOWII の予想 178 (2005-08-08) の注記に出題者自身が
  「$L_s(G) \ge \max\{\lvert N(e)\rvert\} - 2$ … は容易に導ける」と書いている
  (2026-07-27 に一次資料で確認し、初稿の寄与リストから取り下げた)。
  走査ではこの二重星がそのまま証人になり、13,402,070 / 13,402,242 個
  (99.999%) を閉じた (貪欲 159 個、厳密 13 個)。
* **予想 4.1 (B', 本稿)**: $\max_{uv \in E} \lvert N(u) \cup N(v)\rvert
  \ge 2\overline{\ell}(G)$。**B' $\Rightarrow$ 予想 2** (系 4.2)。
* **補題 4.3**: $\sum_{uv \in E} \lvert N(u) \cup N(v)\rvert \ge
  \sum_v d(v)\ell(v)$、等号は三角形なしと同値。
  ($\sum_{uv} \lvert N \cup N\rvert = \sum_v d(v)^2 - 3T$、Gallai の
  $\tau_v = d(v) - \ell(v)$、頂点ごとの $d(v)\tau_v \ge e_v$ による。)
* **予想 4.4 (A, 本稿)**: $n \sum_{uv \in E} \lvert N(u) \cup N(v)\rvert
  \ge 2mS$ (B' の max を平均に置き換えた強化版)。
  **A $\Rightarrow$ B' $\Rightarrow$ 予想 2** (系 4.5)。
* **定理 4.6 (共分散定理)**: $\mathrm{Cov}(d, \ell) \ge 0$、すなわち
  $n \sum_v d(v)\ell(v) \ge 2mS$ ならば A が従う。三角形なしのときは
  $\ell = d$ なので $\mathrm{Cov} = \mathrm{Var} \ge 0$ で自動的に成立
  (系 4.7 — 以前の Cauchy--Schwarz による証明の一般化)。
* **定理 5.1 (帯)**: $2S \le 4n$ (自明帯)、$2S \le n(\Delta+2)$ ($\Delta$ 帯)、
  $n \sum_v d(v)\ell(v) \ge 2mS$ (共分散帯) で予想 2 は閉じる。実測で
  **13,402,228 / 13,402,242 = 99.9999%** が本稿の定理だけで片付き、引用した
  下界 (Kleitman--West, Storer) を足すと残りは**ちょうど 1 個**。
* 等号は 13 個に完全分類: $C_4, \dots, C_{10}$ と $K_{3,3}, Q_3, K_{4,4},
  K_{5,5}, K_{5,5} - M, K_{6,6} - M$ (すべて三角形なし正則、$L_s = 2\Delta - 2$)。
  B' の等号は 8,796 個、A の等号も同数。反例はいずれもゼロ。

**未解決**: A (したがって共分散不等式 $\mathrm{Cov}(d,\ell) \ge 0$) の一般証明。
$\ell$ は $d$ の単調関数ではないので $d$ と $\ell$ の正の相関は自明ではないが、
1340 万個で反例ゼロ。本稿の定理で閉じない 14 個は $n = 9$ の 2 個
(`H?~vfbk` が唯一の hard、`H?~vfrs`) と $n = 10$ の 12 個で、すべて
$\delta \ge 4$。証明書はこの 14 個を graph6 で名指しし、検証器が独立に
数え直して照合する。

> **方法論上の収穫**: 予想を**強くした**ら**証明しやすくなった**。
> 予想 2 (葉数、NP 困難) ← B' (局所量の max) ← A (局所量の平均) ←
> 共分散 $\ge 0$、と登るたびに、max では使えなかった数え上げ・包除の議論が
> 効くようになる。$\Delta$ 帯までで 99.656% だったものが、平均版に移った
> 瞬間 99.9999% になった。

## p0010 の残件: 補題 L1 (予想 154・155 を閉じる鍵)

p0010 では予想 172 を反証し、154 と 155 を次の 1 本に還元した。

> **補題 L1 (未証明)**: ある中心 $v$ が $|R(v)| = 1$ を満たすなら
> $L_s(G) \ge 1 + \max_{u \in C} |R(u)|$。

以下は 2026-07-27 の探索で得た進捗。測定は `tools/l1_coverage.py`
(`python tools/l1_coverage.py 9`、`data/graphs` を読むだけで証明書には触らない)。

### 新しい道具: 精密化した境界補題

p0010 の境界補題 ($G[S]$ が連結なら $L_s \ge |N(S) \setminus S|$) は、
$S$ の全域木の葉を捨てている。捨てずに数えると:

> **精密化した境界補題**: $G[S]$ が連結、$X = N(S) \setminus S$ とする。
> $G[S]$ の全域木 $T_S$ と親割り当て $\varphi : X \to S$
> ($\varphi(y) \in N(y) \cap S$) を任意に取ると
> $$L_s(G) \ \ge\ |X| + \#\{x \in \operatorname{leaf}(T_S) : x \notin \varphi(X)\}.$$

証明は 3 行。$T_S$ に $X$ の各点を $\varphi$ で 1 本ずつぶら下げた木では、
$X$ の点と $\varphi$ に選ばれなかった $T_S$ の葉がすべて葉である。あとは
部分木延長補題 (追加する点は葉として付くので葉数は減らない) で全域木に
延ばすだけ。

実用形は **$|X| + 1$ の判定**である: ある $x \in S$ について
$G[S \setminus \{x\}]$ が連結で、かつ $X$ のどの点も「$S$ 側の隣接点が $x$
ただ 1 つ」ではないなら、$L_s \ge |X| + 1$。

### $r = 2$ の場合は完全に証明できた

$r = \operatorname{rad}(G)$ とする。$n \ge 3$ では $r = 1$ のとき仮定を
満たす中心が存在しない ($|R(v)| = 1$ かつ $\operatorname{ecc}(v) = 1$ は
$n = 2$ を強いる) ので、$r \ge 2$ としてよい。

$r = 2$ とする。$|L_2(v)| = 1$ から $\deg(v) = n - 2$。$R(v) = \{z\}$ に対し
$w \in N(v) \cap N(z)$ を取り $S = \{v, w\}$ と置くと $G[S]$ は連結で
$N(S) \setminus S = V \setminus \{v, w\}$ だから、境界補題より
$L_s \ge n - 2$。一方どの中心 $u$ も $\deg(u) \ge 2$
(次数 1 の中心があるとその隣が全支配点になり $r = 1$) なので
$|R(u)| = n - 1 - \deg(u) \le n - 3$、すなわち $m := \max_u |R(u)| \le n - 3$。
よって $L_s \ge n - 2 \ge m + 1$。$\square$

### $r \ge 3$: 場合分けは要らなかった (2026-09-20)

当初は精密化した境界補題を 3 通りの $S$ に当てて場合分けしていた。

* **場合 A**: $S = B_{r-1}(u)$、$u$ は $|R(u)| = m$ を実現する中心。
* **場合 B'**: $S = B_{r-2}(v)$、$v$ は $|R(v)| = 1$ の中心
  (このとき $N(S) \setminus S = L_{r-1}(v)$)。
* **場合 C**: 既知の二重星定理
  $L_s \ge \max_{uv \in E} |N(u) \cup N(v)| - 2$ ($S$ が辺の場合)。

しかし**境界補題の $S$ は支配的である必要がない**。したがって C は $S$ が辺の
場合、A と B' は $S$ が球の場合にすぎず、3 つは同じ補題の $S$ の取り方の違い
でしかない。場合分けを捨てると L1 は次の 1 本に還元される。

> **還元**: $\partial(G) := \max \{\, |N(S) \setminus S| : G[S]\ \text{連結} \,\}$
> と置く。境界補題より $L_s(G) \ge \partial(G)$ なので、補題 L1 は
> $$\text{仮定の下で}\quad \partial(G) \ \ge\ m + 1
> \qquad (m = \max_{u \in C} |R(u)|)$$
> を示せば足りる。

測定は `tools/l1_reduction.py` (還元そのもの) と `tools/l1_recipes.py`
(下の レシピ階層)。以下の数値はすべてこの 2 本の出力である。

$n \le 9$ の連結グラフ 273,191 個のうち仮定を満たすのは **70,586 個**で、
うち **67,501 個は $r \le 2$** (上の手証明で片付く。証明の各段
$\deg(v) = n-2$・$w$ の存在・$|N(S) \setminus S| = n-2$・$m \le n-3$ も
全件で照合済み)。残る **3,085 個 ($r \ge 3$)** で $\partial(G)$ を全探索した
($2^n$ 個の $S$ を回す)。

| $\partial(G) - m$ | 個数 |
|---|---|
| $+1$ | 325 |
| $+2$ | 981 |
| $+3$ | 1,156 |
| $+4$ | 623 |

**届かない例はゼロ**。しかも $m + 1$ を出す連結 $S$ は小さい。

| $m+1$ を出す連結 $S$ の最小サイズ | 個数 |
|---|---|
| 1 ($\Delta \ge m + 1$) | 2,882 |
| 2 (二重星 = 旧 C) | 170 |
| 3 | 30 |
| 4 | 3 |

$n \le 8$ の 4,294 個については $L_s = n - \gamma_c$ を全探索で厳密に求め、
**L1 の反例はゼロ**だった (`l1_violation: 0`)。

### $S$ を作るレシピの階層 (`tools/l1_recipes.py`)

$\partial(G)$ 自体は $2^n$ 個の $S$ を回さないと出ない。**なぜ効くかが
証明になっている** $S$ の作り方を並べると次の 6 本で、最後の D' を除いて
すべて多項式時間である。

* **R1/球**: $S = B_j(w)$ (全頂点 $w$・全半径 $j$)。$j = 0$ が $\Delta$、
  $j = r-1$ が旧 A、$j = r-2$ が旧 B'。
* **R2 辺**: $S$ が辺。既知の二重星定理そのもの (旧 C)。
* **R3 連結三つ組**: $S$ が連結な 3 頂点集合 (誘導パス $x$–$c$–$y$ か三角形)。
  境界はそのまま $|N(x) \cup N(y) \cup N(c)| - 3$。$|S| = 1$ (R1 の $j=0$)、
  $|S| = 2$ (R2)、$|S| = 3$ (R3) は**どれも同じ不等式**
  $$L_s(G)\ \ge\ \partial(G)\ \ge\ \max\{\,|N(S) \setminus S| \;:\;
  |S| = k,\ G[S]\ \text{連結}\,\}$$
  の $k = 1, 2, 3$ で、$k = 2$ が既知の二重星定理にあたる。
  **$k = 3$ は飾りではなく $n = 10$ で実際に要る** (副産物 4)。
* **J 真部分球**: $B := B_{r-1}(u)$ とする。$S \subseteq B$ が連結で
  $R(u) \subseteq N(S)$ なら $X \supseteq R(u)$。さらに $S \subsetneq B$ なら
  $G[B]$ が連結だから $S$ と $B \setminus S$ の間に辺があり、その端点が
  $X \setminus R(u)$ に入る。よって $|X| \ge m + 1$。
  判定は **1 点抜きだけでよい** ($S \subsetneq B$ が連結かつ支配的なら、
  隣接頂点を 1 つずつ足して連結性を保ったまま $B$ へ伸ばせるので、途中に
  サイズ $|B| - 1$ のものが必ず現れる)。
* **F 相互最遠対**: $v$ を $R(v) = \{u\}$ の頂点とし
  $S = L_{r-1}(u) \cup \{v\}$ とする (副産物 3)。**仮定
  $|R(v)| = 1$ を使う唯一のレシピ**。
* **D' 最小連結化**: $W \subseteq L_{r-1}(u)$ を $R(u)$ の最小支配集合とし、
  $W$ を含む最小サイズの連結集合を $S$ とする。指数時間なので、他のレシピで
  閉じない分だけを引き受ける保険。

仮定を満たし $r \ge 3$ のグラフを「最初に成功したレシピ」で分類すると
($n \le 10$ は連結グラフ 11,989,762 個の走査):

| レシピ | $n \le 9$ | $n \le 10$ |
|---|---|---|
| R1/球 | 3,006 | 69,566 |
| R2 辺 | 56 | 1,558 |
| R3 連結三つ組 | 20 | 338 |
| J 真部分球 | 3 | 27 |
| F 相互最遠対 | 0 | 0 |
| E 錐 (別の構成。副産物 2 を見よ) | 0 | 0 |
| D' 最小連結化 (指数時間) | 0 | 0 |
| **残余** | **0** | **0** |
| (合計) | 3,085 | 71,489 |

球の半径の内訳は $n \le 10$ で $j=0$: 18,701 / $j=1$: 50,391 / $j=2$: 474。
残余が 0 なので

> **補題 L1 は $n \le 10$ のすべてのグラフで成立する** (レシピが各グラフごとに
> $L_s \ge m+1$ の証明を与えるので、厳密な $L_s$ の計算に依らない)。

しかも **D' も E も 1 件も要らない**。$n \le 10$ の全域が
$|S| \le 3$ の小さい連結集合 (R1/R2/R3) と J だけで閉じており、
**残っているレシピはすべて多項式時間**である。

#### どのレシピが効くかを全部測る

上の表は「最初に成功したレシピ」で分類しているので重なりが見えない。
`tools/l1_recipes.py <n> --overlap` で 1 グラフごとに**どれが効くかを全部**
測ると、$n \le 9$ で見えていた構造が $n = 10$ でどこまで保つかが分かる:

| | $n \le 9$ | $n \le 10$ |
|---|---|---|
| J だけ | 2,323 | 53,543 |
| J と F の両方 | 691 | 16,899 |
| F だけ | 71 | 1,025 |
| **J も F も効かない** | **0** | **22** |

$n \le 9$ だけを見ると **J $\lor$ F で全部閉じる**ので、証明すべきことは
「仮定を満たし $r \ge 3$ なら J か F のどちらかが効く」の 1 点に畳めているよう
に見える。**これは $n = 10$ で破れる**: J も F も効かないグラフが 22 個あり、
うち 21 個は R1 か R2 が拾うものの、**R1・R2・J・F・E がそろって外れるものが
ちょうど 1 個**残る。それが副産物 4 の `I?BD?pWco` で、R3 を足す理由になった。

$n \le 9$ で見えていた細かい規則性も $n = 10$ で軒並み破れる:

* J が破れるのは 1,047 個で、$r = 3$ が 1,041・**$r = 4$ が 6**
  ($n \le 9$ では全部 $r = 3$ だった)。
* そこで F の証人 $v$ が持つ $B$-隣人は 2 個が 1,671・**3 個が 26**
  ($n \le 9$ では 99 組すべてが 2 個だった)。
* 相互最遠対を持つ 20,223 個のうち F が閉じるのは 17,924 個で、残る
  2,299 個は $G[S]$ が非連結 ($n \le 9$ では 43 個で、全部 J が拾っていた)。

$n \le 9$ の「すべて $r = 3$」「$B$-隣人はちょうど 2」「J $\lor$ F で閉じる」は
どれも標本が小さいことによる偶然で、一般証明の足場には使えない。

### 副産物 1: 深さ $r-2$ 以下の葉は必ず余る

$S = B_{r-1}(u)$ では $X = R(u)$ ちょうどだが、$R(u)$ の点は距離 $r$ にある
ので $S$ 内の隣接点は必ず距離 $r-1$、すなわち
$\varphi(X) \subseteq L_{r-1}(u)$ である。よって精密化した境界補題から

> $B_{r-2}(u)$ の中に $G[B_{r-1}(u)]$ の非切断点が 1 つでもあれば
> $L_s(G) \ge m + 1$。

これは旧「場合 A」の精密版で、レシピ J に含まれる (そんな点は $R(u)$ を
支配しないので、抜いても支配性が落ちない)。

### 副産物 2: 仮定が効く場所と、R1 が届く範囲がちょうど決まった

R1・R2・R3・J・E・D' はどれも $|R(v)| = 1$ という仮定を使っていない (使うのは
F だけで、それは副産物 3 で切り出した)。仮定は本当に必要で、還元先の不等式 $\partial(G) \ge m+1$ 自体が仮定なしでは偽である。
証人は奇閉路で、$C_5$・$C_7$・$C_9$ はどれも $m = 2$、$\partial = 2$ であり、
そして**どの頂点も最遠点を 2 つ持つ**ので仮定を満たさない。

R1 が届く範囲は完全に決まる。$S = B_j(w)$ の境界は層そのもの
($|N(S) \setminus S| = |L_{j+1}(w)|$) なので

$$\partial(G)\ \ge\ \max_{w,\,j} |L_j(w)|,$$

しかも中心 $u$ の最終層が $R(u)$ だから右辺は必ず $m$ 以上ある。すなわち

> **R1 が効かないのは、どの頂点から見てもどの層も $m$ 個以下のときに限る。**

$n \le 9$ でそうなるのは 3,085 個中 **79 個** (n=8 が 5、n=9 が 74) で、
**すべて $r = 3$**、$m = 3$ が 5 個・$m = 4$ が 74 個。この 79 個は
R2 辺 56 / R3 連結三つ組 20 / J 3 で閉じる (R3 が 76 個に効くので、R3 を
除いた旧構成では J と F が受け持っていた分をほぼ全部吸収している)。
$n = 10$ だけを見ると仮定を満たし $r \ge 3$
の 68,404 個中 **1,844 個** (合わせて $n \le 10$ で 71,489 個中 1,923 個) で、
内訳は $r=3, m=4$ が 919・$r=3, m=5$ が 923・**$r=4, m=3$ が 2**。
$r = 3$ に限るのは $n \le 9$ までの偶然で、一般には $r \ge 3$ で考える。
層が $m$ で頭打ちということは
$\Delta \le m$ でもあるので、R2 が効くには**次数がほぼ $m$ の 2 頂点が
隣接し、近傍の重なりが小さい**ことが要る ($m = 4$ なら
$|N(x) \cup N(y)| \ge 7$、つまり $|N(x) \cap N(y)| \le 1$)。

さらに別の構成として **レシピ E (錐)** を測った: $C(w)$ を $u$–$w$ 最短路の
合併とし $S = \bigcup_{w \in W} C(w) \setminus \{u\}$ と置くと、$u \notin S$
かつ $u \in N(S)$、$R(u) \cap S = \emptyset$ かつ $R(u) \subseteq N(W)$ なので、
**$S$ が連結でありさえすれば** 計算なしに $X \supseteq R(u) \cup \{u\}$ が
出る。単独では 3,085 個中 2,912 個を閉じる (失敗する 173 個はすべて $r = 3$
で、錐が $u$ を外すと分離する形。いずれも
`tools/l1_recipes.py 9 --overlap` が印字する) が、上の階層では球と J に
完全に吸収された。

### 副産物 3: 仮定を使う最初のレシピ (F 相互最遠対)

以前 D' でしか閉じなかった 10 個を調べると、$m+1$ を出す最小の $S$ が例外なく

$$S \;=\; L_{r-1}(u) \cup \{v\}, \qquad
u \in C,\ |R(u)| = m,\ R(v) = \{u\}$$

の形だった (10 個とも $n = 9$、$r = 3$、$m = 4$、$|S| = 3$、境界 5)。これは
$|R(v)| = 1$ という仮定を使う初めての構成である。一般に次が言える。

> **補題 F.** $r = \mathrm{rad}(G) \ge 3$、$u$ は中心、ある頂点 $v$ が
> $R(v) = \{u\}$ を満たすとする。$S = L_{r-1}(u) \cup \{v\}$ が連結なら
> $$\partial(G)\ \ge\ |N(S) \setminus S|\ =\ |P| + |R(u)| - 1\ \ge\ |R(u)| + 1,$$
> ここで $P := \{p \in L_{r-2}(u) : N(p) \cap L_{r-1}(u) \ne \emptyset\}$。

まず $\mathrm{ecc}(v) = d(v, u) \le \mathrm{ecc}(u) = r$ かつ
$\mathrm{ecc}(v) \ge r$ なので $v$ も中心で $v \in R(u)$ である。
$d(u, v) = r$ より $N(v) \subseteq L_{r-1}(u) \cup R(u)$ なので、境界は
$P$ と $R(u) \setminus \{v\}$ の合併ちょうど、すなわち $|P| + |R(u)| - 1$。

残るのは **$|P| \ge 2$** である。$P = \{p\}$ と仮定する。$L_{r-1}(u)$ の各点は
$L_{r-2}(u)$ 側の隣人を持つが、それは $p$ しかないので $p$ は $L_{r-1}(u)$
全体に隣接する。また層は 1 ずつしか変わらないので、$L_{r-1}(u) \cup R(u)$ から
$B_{r-2}(u)$ へ行く道は必ず $P = \{p\}$ を通る。よって
$x \in B_{r-2}(u)$ に対し $d(v, x) = d(v, p) + d(p, x)$ で、
$d(v, u) = r$ と $d(p, u) = r - 2$ から $d(v, p) = 2$。仮定
$R(v) = \{u\}$ より $x \ne u$ なら $d(v, x) \le r - 1$、したがって
$d(p, x) \le r - 3$。一方 $p$ は $L_{r-1}(u)$ に隣接し $R(u)$ へは距離 2 なので

$$\mathrm{ecc}(p)\ =\ \max(r - 2,\ 2)\ <\ r$$

となり、$r$ が半径であることに矛盾する。∎

$|P| \ge 2$ と境界の等式は $n \le 9$ の全グラフで検算した: 条件を満たす
$(u, v)$ の対 3,148 組すべてで $|P| \ge 2$ (最小値ちょうど 2 が 1,899 組)、
境界も $|P| + |R(u)| - 1$ と完全一致で反例ゼロ。

ただし F が使うのは「$R(v) = \{u\}$ の $v$ が、$m$ を与える中心 $u$ を向いて
いる」という**相互最遠**の形であって、仮定そのものより狭い。仮定が保証するのは
「どこかの中心 $v$ が $|R(v)| = 1$」までで、その唯一の最遠点 $u$ は中心とすら
限らない。実測 (`tools/l1_recipes.py 9 --overlap`、$r \ge 3$ の 3,085 個) では

* 証人 $v$ の最遠点 $u$ が中心でないものを含むグラフ: 2,462
* $|R(u)| = m$ の証人を持つグラフ (= 相互最遠対がある): 805
* うち F が実際に閉じる: 762 (残り 43 は $G[S]$ が非連結。全部 J で閉じる)

つまり F 単独の守備範囲は全体の 1/4 ほどで、残りは J が受け持っている。
$u$ が中心であることは $|P| \ge 2$ の証明で本質的に使っている
($\mathrm{ecc}(u) = r$ が無いと $p$ から遠い層が残り、$\mathrm{ecc}(p) < r$ の
矛盾が出ない)。

### 副産物 4: 難物 1 個の解剖から出た R3 (連結三つ組)

$n \le 10$ で **R1・R2・J・F・E がそろって外れる**グラフはちょうど 1 個、
graph6 で `I?BD?pWco` である。$n = 10$、$r = 3$、$m = 4$、次数列は
$(3,2,1,3,2,2,3,3,3,4)$、中心は $\{0, 3, 5, 6, 7, 9\}$。$m$ を与えるのは
$u = 5$ で、層は

$$L_0 = \{5\},\quad L_1 = \{0, 1\},\quad L_2 = \{6, 8, 9\},\quad
R(5) = \{2, 3, 4, 7\}$$

仮定の証人は $v = 9$ ($R(9) = \{1\}$) ただ 1 つ。**ここで F が効かない理由が
はっきり出る**: $\mathrm{ecc}(1) = 4 > r$ なので頂点 1 は中心ではなく、
$v = 9$ の唯一の最遠点は中心を向いていない。相互最遠対が存在しないので
補題 F の前提がそもそも立たず、J も破れ、R2 は 4 までしか届かない
($m + 1 = 5$ に 1 足りない)。

連結な $S$ を全部試すと $\partial(G) = 5 = m + 1$ で、**最大を与える最小の $S$ は
$\{3, 8, 9\}$ ただ 1 つ**。辺は $9$–$3$ と $3$–$8$ だけ ($8$–$9$ は非辺) なので
これは**誘導パス**で、境界は $\{0, 1, 4, 6, 7\}$ のちょうど 5 個である。

この形を一般化したのが R3 で、二重星定理 ($|S| = 2$) を $|S| = 3$ に伸ばした
だけのもの ($O(n \Delta^2)$)。これを階層に足すと $n \le 10$ の残余・D'・E・F が
すべて 0 になり、**全域が多項式時間のレシピだけで閉じる**。J も F も効かない
22 個のうち 21 個は元から R1/R2 が拾っており、この 1 個も R3 が拾う。

回帰テストは `tests/test_l1_recipes.py::test_hard_graph_needs_the_triple_recipe`
に固定してある (F・J・R2 が外れ R3 だけが届くこと、パス $9$–$3$–$8$ の境界が
ちょうど $m + 1$ であることを毎回確かめる)。

### 次の一手

残る仕事は**反例探しではなく「仮定の下で上のレシピのどれかが必ず効く」の
証明**である。

* **「小さい連結集合だけで足りる」か。** レシピを介さず
  $m+1$ を出す連結 $S$ の**最小サイズ**を直接測ると
  (`tools/l1_recipes.py <n> --small 4`):

  | 最小の $\|S\|$ | $n \le 9$ | $n \le 10$ |
  |---|---|---|
  | 1 (= $\Delta \ge m+1$) | 2,882 | 65,288 |
  | 2 (二重星) | 170 | 5,510 |
  | 3 (連結三つ組) | 30 | 664 |
  | 4 | 3 | 27 |
  | **$k \le 4$ で足りない** | **0** | **0** |

  つまり **$n \le 10$ の全域が $|S| \le 4$ の連結集合だけで閉じる**。J も F も
  E も D' も要らない。しかも $k = 4$ が要る 27 個は、階層表で J が拾っていた
  27 個とちょうど一致する — **J の固有の守備範囲は $k = 4$ そのもの**である。
* **ただし $k$ は $n$ に依らず有界ではない** ので、この線で一般証明は書けない。
  証人は木の族 $T_q$ (`tools/l1_family.py`): 道 $v_1 - v_2 - c - z$ に $v_1$ から
  $a_1, \dots, a_q$ を生やし、各 $a_i$ に葉を 2 枚付ける ($n = 3q + 4$)。
  $C = \{v_1, v_2\}$、$r = 3$、$R(v_1) = \{z\}$ で**仮定を満たし**、
  $m = |R(v_2)| = 2q$ になる。木の境界は $2 + \sum_{x \in S}(\deg x - 2)$ で、
  寄与が正なのは $v_1$ ($q-1$) と各 $a_i$ ($1$) だけ。よって
  $m + 1 = 2q + 1$ に届く連結集合は $v_1$ と全部の $a_i$ を含むものに限られ、
  **最小のものは $\{v_1, a_1, \dots, a_q\}$ ただ 1 つ**、サイズちょうど $q + 1$:

  | $q$ | 2 | 3 | 4 | 5 | 6 | 7 |
  |---|---|---|---|---|---|---|
  | $n$ | 10 | 13 | 16 | 19 | 22 | 25 |
  | $m$ | 4 | 6 | 8 | 10 | 12 | 14 |
  | 最小 $\|S\|$ | 3 | 4 | 5 | 6 | 7 | 8 |

  一方で R1 (球) は $B_1(v_1) = \{v_1, v_2, a_1, \dots, a_q\}$ で
  $2q + 1 = m + 1$ を出すので、$T_q$ は補題 L1 の反例では**ない**。
  読み: $k = 1, 2$ ($\Delta$ と二重星定理)、$k = 3, 4$ という延長は
  $n \le 10$ を閉じる実用的な道具ではあっても、**サイズを縛ったままの
  一般証明には伸びない**。
* **手で組んだ族だけの現象でもない。** $11 \le n \le 16$ の連結グラフを乱択して
  仮定を満たすものを集めると (`tools/l1_family.py` の `hunt`、種 20260921・
  20 万回で 72,114 個)、最小 $|S|$ は 1: 51,098 / 2: 17,886 / 3: 2,961 /
  4: 159 / 5: 9 / 6: 1 と分布する。$k \ge 4$ が普通に湧く。
* **R1 単独でも足りない。** その乱択が拾った $n = 15$ の
  `NkCcCG_C??` + `` `??A?I@?? `` ($r = 4$, $m = 6$) では**最良の球の境界が
  $m = 6$** で、R2・R3・F・E も外れる。届くのは J と D' だけ
  ($\mathrm{D}' = 7$)。$T_q$ と合わせると、サイズ上限つきも R1 単独も落ちるので
  **残るのは D'** である。回帰テストは
  `tests/test_l1_recipes.py::test_ball_recipe_alone_is_not_enough` に固定した。
* $n \le 9$ に限れば **J $\lor$ F** で閉じるが、これは $n = 10$ で 22 個に
  破れる (上の重なり表)。F は補題 F として証明済み (副産物 3) なので、
  この線で押すなら「J が破れるときに相互最遠対が存在し、しかも
  $G[L_{r-1}(u) \cup \{v\}]$ が連結」を示すことになるが、`I?BD?pWco` が
  その反例になっている (証人の最遠点が中心でない)。一般証明を書くなら
  この例外を吸収できる R3 の側を主役にするほうが見込みがある。
* J が破れる形はかなり絞れている。$B := B_{r-1}(u)$ と置くと、J は
  「$x \in B$ を 1 つ抜いても $G[B]$ が連結で、まだ $R(u)$ を支配する」
  という条件だから、破れるのは

  > $B$ のどの点も、$G[B]$ の切断点であるか、$R(u)$ のある点の**唯一の**
  > $B$-隣人であるか、のいずれか

  のとき。$G[B]$ の全域木の葉は切断点でないので、破れるなら
  **$B$-隣人がちょうど 1 つしかない $R(u)$ の点が 2 つ以上ある**。
  $n \le 9$ で J が破れる 71 個はすべて $r = 3$ で、$m = 3$ が 5 個・
  $m = 4$ が 66 個。そこで F を成立させる $v$ は、測った 99 組すべてで
  **$B$-隣人をちょうど 2 つ持つ** (= private な点ではない)。ただし
  $n \le 10$ まで広げると $r = 4$ が 6 個・$B$-隣人 3 個が 26 組あるので、
  この 2 つはどちらも $n \le 9$ 限定の性質である。
* $\partial(G) \ge m+1$ の余裕が $+1$ しかない 325 個が本丸。等号ケース
  ($L_s = m+1$) はここに含まれる。
* $\partial(G)$ 自体が新しい不変量として単独で意味を持つ ($L_s \ge \partial$

## p0011 の第一候補: WOWII 72 / 76 / 84 / 85 (tree(G) の下界 4 本)

`data/refs/wowii_open_items.txt` で状態 `O` のまま残っている
$\mathrm{tree}(G)$ (最大誘導木の位数) の下界のうち、**右辺がすべて
多項式時間で厳密に計算でき、証人が 1 個の誘導木で足りる** 4 本:

| # | 主張 |
|---|------|
| 72 | $\mathrm{tree}(G) \ge \lceil \overline{\mathrm{ecc}} + \max_v \ell(v) / 3 \rceil$ |
| 76 | $\mathrm{tree}(G) \ge \mathrm{freq}[T_{\max}(v)] / \lfloor \overline{\deg} \rfloor$ |
| 84 | $\mathrm{tree}(G) \ge 2\,\mathrm{rad}(G) / \delta(G)$ |
| 85 | $\mathrm{tree}(G) \ge \lceil \sqrt{1 + 2 \min_v \mathrm{dist}_{\mathrm{even}}(v)} \rceil$ |

`wowIIdefs.js` で確認した定義 (2026-07-27): $T(v)$ = $v$ を含む三角形の数、
$\mathrm{freq}[T_{\max}(v)]$ = 最大値 $T_{\max}(v)$ を取る頂点の個数、
$d(G) = \delta$ (最小次数、$D(G)$ が最大次数)、
$\mathrm{dist}_{\mathrm{even}}(v)$ = $v$ からの距離が偶数の頂点の個数
($v$ 自身を含むので $\ge 1$)。

この批が p0011 に向く理由:

* **証人は p0005 と同型**: $T$ が木を誘導すれば $\mathrm{tree}(G) \ge |T|$。
  グラフ 1 個につき頂点集合 1 個を渡せば 4 本すべてが線形時間で閉じる。
  NP 困難な $\mathrm{tree}$ を検証器が解き直す必要がない
  (等号の分類だけ p0005 と同じ例外リスト方式)。
* **手証明が付きそうなものが混じっている**: 最短路は誘導路なので
  $\mathrm{tree}(G) \ge \mathrm{diam}(G) + 1 \ge \mathrm{rad}(G) + 1$。
  $\delta \ge 2$ なら $2\,\mathrm{rad}/\delta \le \mathrm{rad} \le \mathrm{tree}$
  で 84 は即座に従うので、残るのは $\delta = 1$ の場合だけ。
* **72 は p0010 の予想 172 と同じ読み方の曖昧さ**をもつ
  (`CEIL[average of ecc(v) + maximum of l(v) /3]` は
  $\lceil (\overline{\mathrm{ecc}} + \max \ell)/3 \rceil$ とも
  $\lceil \overline{\mathrm{ecc}} + \max \ell / 3 \rceil$ とも読める)。
  p0010 と同じく**両方の読みで走査**して、反証なら両方で反証する。

### 手証明の到達点と、残余が硬い理由 (2026-07-28)

道具は 2 本だけ: $t \ge D + 1$ (最短路は誘導路) と $t \ge \ell_{\max} + 1$
(局所独立集合 + 中心の頂点が誘導星を張る)。ここから

| 主張 | 条件 |
|------|------|
| 72a は成立し、**天井を取っても決して tight にならない** | 無条件 |
| 72b | $\ell_{\max} \le 3$ または $3D \le 2\ell_{\max} + 3$ |
| 84 (狭義) | $\delta \ge 2$ |
| 84 | $\delta = 1$ かつ $\max(D, \ell_{\max}) \ge 2r - 1$ |
| 76 が等号 | $G$ が木 |

$n \le 9$ の連結グラフ 273,192 個での残余は、72b が 96,234 → **5,752**、
84 が 67,395 → **515** に減る (下段の条件を足した効果)。残りが硬い理由:

* **2 本の補題は足せない**。$t \ge D + \ell_{\max} - 1$ が言えれば 72b は
  完全に片付くが、これは**偽**。$C_4$ の 1 頂点に葉を 1 枚つけた `DEw` が
  $D = 3$, $\ell_{\max} = 3$, $t = 4 < 5$ で反例。得られる下界は
  $t \ge \max(D, \ell_{\max}) + 1$ 止まり。
* **84 の残余は等号を含む**。$C_6$ の 1 頂点に葉を 1 枚つけた `F?qb_` は
  $\delta = 1$, $r = 3$, $D = 4$, $\ell_{\max} = 3$ で残余条件を満たし、かつ
  $t = 6 = 2r$ で**等号**を達成する。狭義の不等式しか生まない議論では
  この残余は原理的に閉じない。
